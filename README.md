# Full Simulation Workflow with REANA & Snakemake Tutorial

This tutorial is made to help users who want to reproduce simulated datasets or simulate their own collision
dataset as long as they have access to CERN's resources. 

The tutorial goes through setting up the needed environment and teaching the user on how much time and storage the workflow will take the user.

The tutorial can be found [here](https://cms-opendata-workshop.github.io/tutorial-lesson-full-simulation-reana/).
